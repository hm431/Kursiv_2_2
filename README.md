# pr-food

Qt/C++ desktop-приложение для ведения базы данных заведений общественного питания (рестораны и магазины) с поиском, редактированием, визуализацией и многоязычным интерфейсом. Курсовая работа по ООП.

## Описание

Программа представляет собой настольное приложение на базе Qt Widgets, которое позволяет:

- Загружать и сохранять список заведений (рестораны, магазины) из текстового файла с разделителем `;`.
- Просматривать данные в таблице (Model/View) с поддержкой делегата чекбоксов для булевых полей.
- Добавлять и удалять записи прямо из интерфейса.
- Выполнять текстовый поиск/фильтрацию по таблице через прокси-модель (`QSortFilterProxyModel`).
- Строить диаграммы и графики на основе данных (`Qt Charts`).
- Переключать язык интерфейса в рантайме: русский, английский, немецкий.

Каждое заведение описывается классом `Food` со следующими полями:

| Поле        | Описание                                             |
|-------------|------------------------------------------------------|
| `FOName`    | Название заведения                                   |
| `FOTipe`    | Тип (`shop` / `restaurant`)                          |
| `FOTime`    | Время работы                                         |
| `FOSite`    | Сайт                                                 |
| `FODelivery`| Наличие доставки                                     |
| `FOParking` | Наличие парковки                                     |
| `FOGrup`    | Группа (`network` — сетевое, `ones` — единичное)     |
| `FOMark`    | Оценка (число с плавающей точкой)                    |

## Технологии

- **Язык:** C++17
- **Фреймворк:** Qt 5 / Qt 6 (`QtWidgets`, `QtCharts`)
- **Сборка:** qmake (`Kursov2_2.pro`)
- **Архитектура:** Model/View (`QAbstractTableModel`, `QSortFilterProxyModel`, `QStyledItemDelegate`)
- **Локализация:** `QTranslator` + `.ts`/`.qm` файлы (ru, en, de)

## Формат входных данных

Файл `pr-food.txt` — текстовый, одна запись на строку, поля разделены `;`:

```
Название;Тип;Время работы;Сайт;Доставка;Парковка;Группа;Оценка
```

Пример:

```
Piterochka;shop;c_8:00_до_23:30;true;true;false;network;4.1
Yakitoria;restaurant;c_8:00_до_23:30;true;true;false;network;4.3
Burger-King;restaurant;c_9:00_до_23:30;true;true;false;network;3.9
```

## Сборка и запуск

### Требования

- Qt 5.12+ или Qt 6.x с модулями **Widgets** и **Charts**
- Компилятор с поддержкой C++17 (GCC, Clang или MSVC)
- `qmake` или Qt Creator

### Сборка через Qt Creator

1. Открыть `Kursov2_2.pro` в Qt Creator.
2. Настроить kit (выбрать установленную версию Qt).
3. Запустить сборку (`Ctrl+B`) и затем запуск (`Ctrl+R`).

### Сборка из командной строки

```bash
git clone https://github.com/hm431/Kursiv_2_2.git
cd Kursiv_2_2
mkdir build && cd build
qmake ../Kursov2_2.pro
make            # nmake / mingw32-make на Windows
./Kursov2_2     # запуск собранного бинарника
```

### Обновление переводов

После изменения строк интерфейса:

```bash
lupdate Kursov2_2.pro     # обновить .ts файлы
linguist tr/Kursov2_2_ru_RU.ts   # перевод в Qt Linguist
lrelease Kursov2_2.pro    # сгенерировать .qm
```

## Использование

После запуска главное окно содержит:

- **Меню «Файл»** — открыть, сохранить, сохранить как, добавить, удалить запись.
- **Поле поиска** — фильтрует таблицу по введённой подстроке в реальном времени.
- **Меню «Язык»** — переключение интерфейса между русским, английским и немецким.
- **Меню «Графики»** — отображение диаграмм по данным таблицы.
- **Меню «О программе»** — информация об авторе и версии.

Для первого запуска можно открыть пример `pr-food.txt`, поставляющийся в репозитории.
